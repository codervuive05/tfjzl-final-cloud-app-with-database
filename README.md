# Online Course Assessment Feature

Django course application with Question, Choice, Submission models, seven registered admin models, Bootstrap course lessons, and exam submission/results.

Adapted from the locally saved IBM course lab (Apache-2.0; LICENSE retained).

Run: install requirements, run `python manage.py migrate`, create a superuser with `python manage.py createsuperuser`, then `python manage.py runserver`.

The development secret is a non-production placeholder; set DJANGO_SECRET_KEY for deployment.
